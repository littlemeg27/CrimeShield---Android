# CrimeShield Android

Android app for community safety awareness. Built for Full Sail University Project and Portfolio II: Computer Science.

CrimeShield is designed to help people see nearby risk information and keep safety tools in one place. The iOS companion is [CrimeShield-iOS](https://github.com/littlemeg27/CrimeShield-iOS).

## Features

- Native Android client
- Navigation between main safety screens
- Kotlin + Java codebase from the course build

## Tech stack

| Layer | Tools |
|---|---|
| Languages | Kotlin, Java |
| Platform | Android |
| Build | Gradle / Android Studio |

## Project status

Course project. App module is in the `CrimeShield` folder.

## Getting started

1. Clone the repo
2. Open the project in Android Studio
3. Sync Gradle
4. Run the `CrimeShield` app module

```bash
git clone https://github.com/littlemeg27/CrimeShield---Android.git
```
